# GH-300 flashcards

A mobile-first study aid for [Exam GH-300: GitHub Copilot](https://learn.microsoft.com/en-gb/credentials/certifications/resources/study-guides/gh-300).

## Features

- 35 concise cards across every exam skill area
- Tap or press <kbd>Space</kbd> to reveal answers
- Swipe, use arrow keys, or use the navigation buttons to change cards
- Topic filters, shuffle, and locally saved study progress
- A Microsoft Learn source link on every card
- Dependency-free static files suitable for GitHub Pages

## Run locally

Open `index.html` in a browser, or serve the repository with any static file server.

Run the JavaScript syntax check with:

```sh
npm test
```

## Publish with GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, then select the default branch and the repository root (`/`).

## Disclaimer

This is a community study aid, not an official Microsoft product. Product capabilities and exam objectives can change; follow each card’s Microsoft Learn link and check the official study guide before taking the exam.
